Drop uploaded site assets here (logo, Open Graph image, etc.).

Suggested filenames:
- `logo.svg` / `logo.png` — site logo, referenced from `Header.tsx` / `Footer.tsx`
- `og-image.png` — 1200x630 Open Graph / social share image, referenced from `src/app/layout.tsx` metadata

Files in `public/` are served at the site root, e.g. `public/images/logo.png` → `/images/logo.png`.
